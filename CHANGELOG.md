# История изменений L‑KA

Здесь фиксируются публичные изменения продукта и его GitHub-витрины.

## 2026-09-07 — публичный GitHub L‑KA

- запущен официальный публичный репозиторий L‑KA;
- добавлена русская продуктовая страница;
- добавлена английская версия;
- добавлены инструкции по установке на Web, Android, Windows, macOS и iPhone/iPad;
- добавлена документация L‑KA для бизнеса;
- добавлены FAQ, поддержка и политика безопасности;
- добавлены публичные формы обратной связи через GitHub Issues.

## Desktop

Текущая ветка desktop-клиента использует линейку версии **1.0.5**. Актуальные установочные файлы следует получать с официальной страницы:

https://l-ka.ru/download/

Официальный Android-клиент распространяется через Google Play.

https://play.google.com/store/apps/details?id=ru.lka.elka
