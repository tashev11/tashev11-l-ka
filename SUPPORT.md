# Поддержка L‑KA

Этот репозиторий можно использовать для публичных сообщений об ошибках, предложений и вопросов по документации.

Для обращения напрямую используйте официальный адрес:

**support@l-ka.ru**

## Перед созданием Issue

Проверьте, что проблема воспроизводится повторно, и по возможности обновите приложение или страницу до актуальной версии.

## Что указать в сообщении об ошибке

- платформа: Web / Android / Windows / macOS / iPhone/iPad;
- версия операционной системы;
- браузер, если проблема в веб-версии;
- последовательность действий до появления ошибки;
- ожидаемый результат;
- фактический результат;
- скриншот или запись экрана, если они не содержат приватных данных.

## Не публикуйте персональные данные

GitHub Issues публичны. Не размещайте там:

- пароль или код входа;
- токены, cookies и API-ключи;
- приватную переписку;
- номера телефонов, email и другие данные пользователей без необходимости;
- внутренние данные компаний и клиентов.

## Проблемы безопасности

Если ошибка может привести к несанкционированному доступу, утечке данных или обходу авторизации, не создавайте публичный Issue. Используйте инструкцию из [SECURITY.md](SECURITY.md) и напишите на **support@l-ka.ru** с темой `Security / Уязвимость L-KA`.
