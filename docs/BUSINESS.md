# L‑KA для бизнеса

L‑KA позволяет использовать мессенджер не только для личного общения, но и как канал связи компании с посетителями сайта.

## Как это работает

Компания устанавливает на сайт чат-виджет L‑KA. Посетитель пишет сообщение прямо на сайте, а оператор получает обращение в рабочем интерфейсе L‑KA и продолжает диалог.

**Посетитель сайта → чат-виджет → оператор → диалог**

## Что получает бизнес

- единый канал входящих обращений с сайта;
- чат-виджет, который можно встроить в сайт;
- рабочее место оператора;
- возможность организовать работу нескольких операторов;
- историю общения с клиентами внутри бизнес-части;
- использование L‑KA как одного интерфейса для внутреннего и клиентского общения;
- возможность подключать интеграции к бизнес-процессам компании.

## Где это полезно

L‑KA Business может использоваться на сайтах компаний, которым важно быстро принимать обращения посетителей:

- услуги;
- продажи;
- интернет-магазины;
- агентства;
- недвижимость;
- медицина и сервисные компании;
- B2B;
- техническая поддержка;
- корпоративные сайты.

## Сценарий

1. Посетитель открывает сайт компании.
2. Нажимает на чат L‑KA.
3. Отправляет вопрос.
4. Обращение появляется у оператора.
5. Оператор отвечает клиенту.
6. Диалог остаётся в рабочем интерфейсе для дальнейшей обработки.

## Подключение

Для информации о подключении бизнес-функций и чат-виджета используйте официальный сайт:

**https://l-ka.ru**

## Для разработчиков и интеграторов

L‑KA использует веб-технологии реального времени. Возможности конкретной интеграции зависят от сценария сайта и CRM клиента.

Если вы хотите предложить новую публичную интеграцию или тип подключения, создайте Feature Request в GitHub Issues этого репозитория.

> Не публикуйте в Issues API-ключи, секреты, реальные данные клиентов или внутренние адреса корпоративных систем.
