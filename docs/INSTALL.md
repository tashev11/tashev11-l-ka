# Установка L‑KA

L‑KA можно использовать в браузере, установить на Android, Windows/macOS или добавить на главный экран iPhone/iPad как веб-приложение.

## Web

Самый быстрый способ начать работу:

1. Откройте [app.l-ka.ru](https://app.l-ka.ru).
2. Войдите в существующий аккаунт или используйте приглашение.
3. Разрешите уведомления, если хотите получать сообщения вне активной вкладки.

## Android

L‑KA доступен как отдельное приложение для Android.

**Google Play:** https://play.google.com/store/apps/details?id=ru.lka.elka

После установки войдите в тот же аккаунт, который используете в веб-версии.

## Windows

1. Откройте [l-ka.ru/download](https://l-ka.ru/download/).
2. Скачайте установщик L‑KA для Windows.
3. Запустите установщик.
4. После установки откройте «Элька» из меню Пуск или с рабочего стола.

Для Windows также может использоваться portable-сборка, если она опубликована на странице загрузки.

## macOS

1. Откройте [l-ka.ru/download](https://l-ka.ru/download/).
2. Скачайте версию для своей архитектуры Mac, если на странице доступны несколько вариантов.
3. Откройте DMG-файл.
4. Перетащите «Элька» в Applications.
5. Запустите приложение.

## iPhone и iPad

На iPhone/iPad L‑KA устанавливается как веб-приложение через Safari.

1. Откройте **Safari**.
2. Перейдите на [app.l-ka.ru](https://app.l-ka.ru).
3. Нажмите кнопку **«Поделиться»**.
4. Прокрутите меню и выберите **«На экран Домой»**.
5. При необходимости измените название ярлыка.
6. Нажмите **«Добавить»**.

После этого иконка L‑KA появится на главном экране и приложение можно будет запускать отдельно от обычной вкладки Safari.

> Если пункта «На экран Домой» не видно, откройте список действий в меню «Поделиться» и найдите его там.

## Обновления

Веб-версия и установленная веб-версия на iPhone/iPad получают изменения через веб-приложение.

Десктопные сборки L‑KA используют официальный канал обновлений на `l-ka.ru/download/`.

Для Android обновления распространяются через Google Play.
