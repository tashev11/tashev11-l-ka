# Как помочь L‑KA

Спасибо за интерес к L‑KA. Этот репозиторий не содержит закрытый серверный исходный код продукта, но используется для публичной документации, обратной связи, сообщений об ошибках и предложений.

## Можно помочь так

- сообщить об ошибке;
- предложить новую функцию;
- предложить улучшение интерфейса или установки;
- улучшить публичную документацию;
- предложить новый сценарий интеграции для бизнеса;
- сообщить о неточности в README или FAQ.

## Хороший Bug Report

Укажите:

1. платформу и версию ОС;
2. браузер или тип приложения;
3. шаги воспроизведения;
4. ожидаемый результат;
5. фактический результат;
6. дополнительные материалы без приватных данных.

## Хороший Feature Request

Опишите не только функцию, но и проблему пользователя:

- кто сталкивается с проблемой;
- в каком сценарии;
- что приходится делать сейчас;
- как предлагаемое изменение поможет.

## Безопасность

Уязвимости нельзя публиковать в открытых Issues. Следуйте [SECURITY.md](SECURITY.md).

## Персональные данные

Не публикуйте реальные сообщения, пароли, токены, cookies, клиентские базы и другие чувствительные данные.
