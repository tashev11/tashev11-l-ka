## Что такое L‑KA

**L‑KA (Элька)** — действующий кроссплатформенный мессенджер с доступом по приглашению. Он объединяет личные и групповые чаты, звонки, каналы, сторис, веб-приложение, Android и desktop-клиенты, а также инструменты для общения бизнеса с посетителями сайтов.

Для регистрации не требуется обязательная привязка к номеру телефона или email. Один аккаунт можно использовать на разных устройствах.

### Возможности

- 💬 личные и групповые чаты;
- ↩️ ответы, реакции и закреплённые сообщения;
- 🎙️ голосовые сообщения;
- 📢 каналы для публикаций и объявлений;
- 👥 группы с ролями владельца и модератора;
- 🟣 сторис друзей и каналов;
- 📞 голосовые и видеозвонки;
- ✓ статусы «отправлено / доставлено / прочитано»;
- ⌨️ индикатор «печатает…»;
- 🔔 push-уведомления;
- ☀️ светлая и 🌙 тёмная темы;
- 📎 синхронизация сообщений, звонков и файлов между устройствами;
- 🏢 бизнес-кабинет и рабочее место оператора;
- 💬 встраиваемый чат-виджет для сайтов.

## 🔐 Приватность и безопасность

L‑KA строится вокруг закрытого доступа и защиты пользовательских данных.

- доступ в сеть — по приглашению;
- обязательный номер телефона или email для регистрации не нужен;
- передача данных защищена TLS;
- сообщения при хранении защищаются шифрованием;
- для секретных чатов предусмотрено сквозное шифрование;
- содержимое сообщений не используется для рекламы;
- рекламные и сторонние tracking-cookies не используются.

Официальная политика конфиденциальности: **[l-ka.ru/privacy](https://l-ka.ru/privacy)**.

Для сообщения об уязвимости: **[SECURITY.md](SECURITY.md)**.

### 🍎 iPhone и iPad

На iPhone/iPad L‑KA устанавливается как веб-приложение:

1. Откройте **[app.l-ka.ru](https://app.l-ka.ru)** в Safari.
2. Нажмите **«Поделиться»**.
3. Выберите **«На экран Домой»**.
4. Подтвердите добавление.
5. Иконка L‑KA появится на главном экране как у обычного приложения.

Подробно: **[Установка L‑KA](docs/INSTALL.md)**.

## 🏢 L‑KA для бизнеса

L‑KA — это не только мессенджер. В продукт встроен канал общения компании с посетителями сайта.

Компания может установить **чат-виджет L‑KA**, принимать обращения и работать с ними через кабинет оператора.

```text
Посетитель сайта
        ↓
   Чат-виджет L-KA
        ↓
      Оператор
        ↓
  Диалог и обработка
```

Это подходит для продаж, поддержки, услуг, агентств, недвижимости, B2B и других компаний, которым важно быстро отвечать посетителям сайта.

Подробнее: **[L‑KA для бизнеса](docs/BUSINESS.md)**.
