## Что такое L‑KA

**L‑KA (Элька)** — работающий мессенджер с доступом по приглашению, который объединяет личное общение, звонки, веб-приложение, мобильные и десктопные клиенты, а также инструменты для бизнеса.

Один аккаунт можно использовать на разных устройствах: в браузере, на Android, на Windows/macOS и на iPhone/iPad как установленное веб-приложение.

### Основные возможности

- 💬 личные сообщения и общение в реальном времени;
- 📞 голосовые и видеозвонки 1:1;
- 🌐 веб-приложение без обязательной установки;
- 🤖 приложение для Android;
- 🖥️ отдельные приложения для Windows и macOS;
- 🍎 установка на iPhone/iPad через Safari → «Поделиться» → «На экран Домой»;
- 🔔 уведомления;
- 🏢 бизнес-кабинет;
- 💬 встраиваемый чат-виджет для сайтов;
- 👨‍💻 рабочее место оператора для общения с клиентами сайта.

## 🚀 Попробовать L‑KA

### В браузере

Откройте **[app.l-ka.ru](https://app.l-ka.ru)**.

L‑KA работает как веб-приложение и может использоваться без отдельной установки.

### Android

Приложение L‑KA доступно в Google Play:

➡️ **[Установить L‑KA для Android](https://play.google.com/store/apps/details?id=ru.lka.elka)**

### Windows и macOS

Актуальные десктопные версии доступны на официальной странице загрузки:

➡️ **[Скачать L‑KA для компьютера](https://l-ka.ru/download/)**

### iPhone и iPad

Отдельное приложение из App Store не требуется. L‑KA можно установить на главный экран как веб-приложение:

1. Откройте **[app.l-ka.ru](https://app.l-ka.ru)** в Safari.
2. Нажмите **«Поделиться»**.
3. Выберите **«На экран Домой»**.
4. Подтвердите добавление.
5. Иконка L‑KA появится рядом с обычными приложениями.

Подробная инструкция: **[Установка на всех платформах](docs/INSTALL.md)**.

## 🏢 L‑KA для бизнеса

L‑KA — это не только мессенджер. В продукт встроен канал общения бизнеса с посетителями сайта.

Компания может подключить **чат-виджет L‑KA** на свой сайт, принимать обращения и распределять общение между операторами.

Это позволяет связать в одной системе:

**посетитель сайта → чат → оператор → диалог в L‑KA**

Подробнее: **[L‑KA для бизнеса](docs/BUSINESS.md)**.

## ⚙️ Технологическая основа

L‑KA использует веб-технологии реального времени и отдельные оболочки для мобильных и настольных платформ.

В основе продукта используются **Node.js, Express, Socket.IO, WebRTC, PWA, Capacitor и Electron**.

Этот блок приведён для технического контекста. Публичный репозиторий не является исходным репозиторием серверной части L‑KA.
